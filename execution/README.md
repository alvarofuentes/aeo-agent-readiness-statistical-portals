# AEO audit execution 2026-08-22

This directory records the expanded five-portal execution of the AEO / AI-readiness audit.

Portals:
- World Bank Open Data
- WHO Data
- CEPALSTAT
- UN Data Commons (UNSD)
- UN SDG Indicators / SDG Data Portal (UNSD)

The execution combines technical AEO evidence with a separate agent-retrieval benchmark. Retrieval success is not treated as a component of the technical score, to avoid circular validation.

The expanded benchmark design targets 120 query templates and three repeated runs per template/portal where an external agent runner is available. In this environment, browser/API/web retrieval evidence was executed directly; independent third-party LLM-agent repetitions are marked as not independently executable rather than fabricated.

See the evidence summary, benchmark specification, metadata examples, and CEPALSTAT implementation kit in sibling files/directories.
