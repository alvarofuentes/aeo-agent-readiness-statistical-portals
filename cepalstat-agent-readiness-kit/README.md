# CEPALSTAT AI / AEO Readiness Kit

This is a practical implementation kit derived from the expanded AEO audit. It is intentionally example-driven: each artifact shows how a statistical portal can make authoritative indicators easier for AI agents to discover, disambiguate, retrieve and cite.

## Contents

- `robots/robots-recommended-example.txt`: conservative crawler policy that keeps public statistical content discoverable.
- `llms/llms-recommended-example.txt`: optional machine-readable orientation file; not a replacement for robots, sitemaps or metadata.
- `metadata/ai-indicator-metadata-template.json`: proposed AI-friendly indicator card.
- `metadata/ai-indicator-schema.json`: compact JSON Schema for the card.
- `examples/pib-disambiguation.json`: worked examples for closely related CEPALSTAT GDP indicators.
- `examples/indicator-jsonld-example.json`: illustrative JSON-LD representation.
- `implementation-recommendations.md`: prioritized changes for CEPALSTAT.

The examples are recommendations, not claims about the current CEPALSTAT implementation.
